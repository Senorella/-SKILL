# 配色规则（v4.24 配色决策框架 + v4.26 黑底高饱和）

> 对应 SKILL.md 的 v4.16 / v4.21 / v4.24 / v4.26。配色**必须有依据**，禁止凭感觉。

## 配色决策五维度（拿到主题先逐维度填一句依据）

| 维度 | 判断问题 | 配色倾向 |
|---|---|---|
| ① 色彩倾向 | 主题色彩丰富度 | 丰富绚烂→黑底；清雅含蓄→白底 |
| ② 情绪氛围 | 轻松/严肃/先锋/仪式？ | 轻松→暖·明快·浅底；严肃→沉稳留白；先锋→黑底强对比；仪式→深底金 |
| ③ 目标受众 | 谁会来看 | 年轻→明快可大胆；高端→克制低饱和少色留白；家庭→温暖柔和；文艺→雅致适中；大众→鲜明高辨识 |
| ④ 颜色数量 | 活动适合几色 | 高端极简→1-2色；常规→2-3色；热闹节庆→3色 |
| ⑤ 饱和度 | 颜色该多浓 | 高端清雅→低(S0.3-0.4)；温暖大众→中(S0.4-0.6)；年轻强视觉→高(S0.6-0.8) |

**决策流程**：逐维度填依据 → 综合出「底色/色相/颜色数/饱和度」→ 先输出「配色决策卡」再出图。维度冲突时以**氛围 + 受众**优先。

## 底色铁律

- 底色只能是**纯白 `#FFFFFF` 或纯黑 `#000000`**（生成后程序化验证四角色值）。
- 暖白/米白/暖杏一律不用做底色；「温暖」靠墨点与文字色相表达，不靠底色。

## 饱和度与底色绑定（v4.26）

| 底色 | 彩色饱和度要求 |
|---|---|
| **黑底** | 所有彩色（标题/传播语/日期/CTA）一律**高饱和 S≈0.6–0.8 + 高亮度 L≈0.6–0.75**。黑底会「吃掉」低饱和彩色（发灰发闷） |
| **白底** | 按主题：清雅低 S≈0.3–0.4 / 温暖大众中 S≈0.4–0.65 / 年轻强视觉高 S≈0.6–0.8 |

## 颜色数量铁律

- 文字颜色 **≤3 色（灰阶不计）**。
- 单色系统（1 色相 + 灰阶）只适合高端/极简/文艺克制类；**热闹/市集/节庆/亲子必须 2–3 色组合，禁止单色**。
- 口诀：越热闹接地气色相越多，越高级克制色相越少。

## 色相取材原则

- **从活动主题的工艺/材质/文化本身取材**，不套用过往项目的惯用色。
- **逐句对照文案意象**：如「大地之舞」→ 大地赭、「从草原到雪山」→ 草原绿，让配色本身讲故事。
- 反面踩坑：非遗市集一度沿用敦煌的朱砂/靛蓝/鎏金（红黄蓝），被纠正为染色工艺色（朱砂红/松石绿/柿染橙）。
