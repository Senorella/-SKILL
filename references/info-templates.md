# 信息文案模板（v4.x）

> 对应 SKILL.md v4.13 三方案的信息模块。**旧 v3.0 的 EXHIBITIONS 字典结构已废弃**，现在每个脚本独立定义文案常量。

## 标准文案字段（每个展览都需提供）

| 字段 | 示例 | 落位 |
|---|---|---|
| 名称（完整标题） | 大地之舞——跟着风的方向起舞 | 标题组（像素体超大、主色） |
| 传播语 | 从草原到雪山，一步一故乡 | 标题下方 42px 辅色 |
| 行动提示（CTA） | 预约观展 / 预约购票 / 免费入场 / 预约选座 | 右下角 + 64px 二维码 |
| 展期 | 2027.6.12 — 6.28 | 右上时间模块（主色） |
| 开放时间 | 周六至周日 15:00–17:00 | 右上时间模块下方 |
| 地点 | 城市文化中心一层沉浸展厅 | 左下「地点」模块 |
| 主办方 | 城市文化中心 | 左下「主办」模块 |

## 时间模块（右上，右对齐）

```
时间 Time              ← 22px 灰标签
2027.6.12 — 6.28       ← 54px 像素体主色
周六至周日 15:00–17:00  ← 26px 灰白
```
实测墨迹矩形约 `(627, 45) – (984, 180)`（左缘由展期大数字决定）。

## 底部信息区（左下地点/主办 + 右下 CTA/二维码）

- 左下「地点 Location」+ 场馆名（白加粗）、「主办 Organizer」+ 主办方（灰）。
- 右下 CTA（强调色）+「扫码…」小字 + 64px 二维码，二维码与 CTA 文字**顶边/右缘对齐**。

## 二维码

- 尺寸 64px（原 90px 偏大）。
- `make_qr(url)` + `paste_qr(img, qr, (x, y), 64)`。
- URL 通常填 `https://weixin.qq.com` 占位。

## 标题完整呈现（v4.25）

标题含连接符时前后都是标题，完整呈现；副标题（标题后半句）与主标题**统一字体/字号/颜色**，分多行排，传播语降一级。

## 多展览复用

换展览时：新脚本里改文案常量 + 配色常量 + 底图源文件名，版式逻辑不动。参考既有脚本（`make_poster_dance.py` / `make_poster_sound.py` / `make_poster_film.py` / `make_poster_craft.py` 等）。
