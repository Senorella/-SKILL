# 版式规则（v4.13 三方案 + v4.14 左置露白 + v4.15 标题下沉 + v4.20 居中 + v4.27 横版）

> 对应 SKILL.md 的 v4.13–v4.20、v4.27。**旧 v3.5 的「白底信息区五块表格」版式已废弃。**

## 横版 16:9 排版（v4.27，潍坊风筝展定稿）

用户要求横版主视觉时（区别于竖版 1024×1536），采用：

- 画布 **1536×864（16:9）**，底色纯白/纯黑。
- 渲染与柔光层同竖版：白底 `global_pad_light(alpha=200)`、黑底 `global_pad_dark(alpha=190, RGB 12,12,14)`，仅一张全图、贴文字前铺完。
- **禁止给文字垫 plaque 实色矩形**（硬衬底形成突兀白/黑块）；可读性靠柔光层，不靠局部垫色。
- **主标题左上**：像素体 ZiYuQuWeiXiangSu 同字体同色同字号分两行，默认 170px，紧凑行距（墨迹间隔约 8px），用 textbbox 实测落位。
- 非遗行 + 工艺行紧跟标题（灰色小字）。
- **右上时间模块 / 右下地点 / 右下二维码三者右边缘对齐同一条线 W-36**；地点右边缘对齐二维码右边缘；预约小字右对齐二维码左边缘。
- 二维码缩小约 48–64px（深底垫纯白底供扫码）。
- 各区块几何零重叠（v4.17 断言）。

## 画布与渲染

- 画布：1024×1536（竖版 2:3），底色纯白 `#FFFFFF` 或纯黑 `#000000`。
- 底图渲染：`render_size_halftone()`（黑底反白点阵）或 `render_size_halftone_light()`（白底正片墨点）。
- 参数：cell=7、contrast=1.35、ink_gamma=0.85、rim=True。

## 三套定稿版式（v4.13）

| 方案 | 版式 | 底图 | 文字 |
|---|---|---|---|
| 一 | 黑底满版 | 黑底变尺寸半调（柔光 alpha 190） | 石绿标题微弱高光 + 鎏金/灰白纯色 |
| 二 | 白底单色 | 纯白底浅点阵 + 同色相全饱和文字 | 单色系统强反差 |
| 三 | 白底灰点阵 | 中性灰墨点（不染色） | 彩字（≤3 色） |

通用：时间模块右上、标题居中偏上（或按底图落位）、地点/主办左下、二维码右下。

## 非满版底图：左置露白（v4.14）

底图是圆形/半圆/方形/局部纹样等无法填充整幅时：
- 不做等比拉伸、不做圆形裁切，把主体**放大后整体左移**，主体中心对准画面约 1/3，右侧约 1/2 露出。
- 文字全部右对齐环绕右侧留白（时间右上 / 标题居中偏上 / 地点主办右下），二维码左下平衡。

## 底图偏上：标题下沉（v4.15）

- 触发：底图主体集中上半、下半留白 ≥1/3。
- 先做行亮度扫描定位主体下缘（**必须在柔光层之前分析**），标题组下沉到主体下缘以下的留白区，底部信息区贴底不动。

## 居中构图两版式（v4.20，话剧《镜中人》定稿）

- **版式一 · 标题居中上置**：主体居中 + 顶部有暗带的素材，标题组全居中，墨迹顶 = 时间模块底 + ≥50px。
- **版式二 · 标题嵌入暗带**：底图「亮上 / 暗带中 / 剪影下」三段式，标题居中放进暗带不压主体；传播语与画面位置语义呼应是加分项。

## 柔光层铁律（v4.8，永久生效）

- 全图**仅一张**柔光层（global_scrim/global_pad），贴文字前铺完，禁止多块半透明色块堆叠。
- 文字与底图层次未拉开时加高 alpha（黑底 185–215 起调），而非局部垫色。

## 文字可读性（v4.23，优先级从高到低）

1. 文字排在底图天然留白处（构图/排版解决）
2. 渲染前源图信息带灰度提亮（`brighten_bands`，正片自然留白，无羽化痕迹）
3. 后期羽化减淡（**最后手段，尽量不用**；目标色必须与底色一致，mask 矩形向外扩 feather+10 补偿边缘衰减）
