## 标题（v4.25 铁律：完整呈现、统一字体/字号/颜色）

- 标题含破折号「——」、冒号「：」等连接符时，**前后内容都是标题、必须完整呈现**，不得把后半句降级为传播语。
- 完整标题**同一个字体、同一个字号、同一个颜色**，分多行排（如「大地之舞——」/「跟着风的方向起舞」两行 200px 像素体同色）。
- 传播语（42px 辅色）必须明显低于标题组，避免被误读为标题。

### 字号参考（像素体单字墨迹高 ≈ 0.36×字号）

| 标题字数 | 参考字号 | 说明 |
|---|---|---|
| 单行 6 字（如「故事讲得很慢」） | 240px | 实测宽 835 < 944 |
| 两行 4+8 字（如「大地之舞——」+「跟着风的方向起舞」） | 200px | 行2 宽 856 < 944 |
| 两行 5+8 字（如「你听——」+「城市白噪音采集计划」） | 180px | 行2 宽 783 < 944 |

## 防重叠（v4.17 铁律 + 全幅大外框字形坑）

- 标题与右上时间模块**几何零重叠是硬红线**，哪怕重叠几像素也判不合格。
- **全幅大外框字形（「圈」「慢」等）墨迹顶偏移远小于普通字**：「慢」@240px 偏移仅 70，普通字 132。整串墨迹顶由这类字决定。
- **必须用整串 `getbbox()` 实测墨迹矩形**，禁止按「0.55×字号」统一估算。踩坑：「故事讲得很慢」的「慢」字顶进右上时间模块，重叠 12px。
- 落位后跑矩形相交断言 `rects_overlap(title_rect, time_rect)`。

## 主标题渐变高光（v4.30 铁律：黑底主标题必加，参数必须落实）

> 起因：v4.30 之前多处只写「黑底加微弱渐变高光」一句话，无具体参数，导致潍坊风筝海报漏实现，且 15% 混白在 170px 像素体上被稀释到几乎不可见（仅 ~5 亮度差）。

- **适用**：黑底 / 深底（深蓝/红/绿等染色深底）的主标题。**白底 / 浅底不加渐变、不加光晕**（避免脏）。
- **渐变方向**：垂直，顶部比主色亮、向下过渡到主色。
- **混白力度（关键参数）**：`c_top = mix(title_c, (255,255,255), 0.30)`。
  - 0.15 是早期错误值——在 150–200px 像素体上被字形高度稀释，实测仅 ~5 亮度差，肉眼几乎不可见。
  - 0.30 实测顶部比底部亮约 12 亮度级，渐变可见且仍克制（符合「立体感收敛」）。
- **光晕**：`glow=title_c, glow_alpha≈18, glow_blur≈10`（可选，仅深底；白底用 `glow=None`）。
- **实现（gradient_text）**：对整行文字 bbox 逐行插值（顶部 c_top → 底部 title_c），以文字 mask 贴回；光晕用 mask 高斯模糊后按 glow_alpha 叠加。脚本见 `kite-poster/make_kite_v3.py` 的 `gradient_text()` / `_mix()`。
- **验证**：出图后程序化采样标题区顶部/底部像素的 RGB，确认亮度差 ≥10 级；若 <8 级说明渐变被稀释，需加大混白力度。

## 其余文字层级（三方案通用）

- 主标题：像素体超大、主色（黑底加微弱渐变高光 + 微弱光晕，仅标题可保留）
- 传播语：42px、辅色（黑底高饱和 / 白底按主题）
- 日期/展期：像素体或雅黑、主色
- 地点/主办/英文/标签：灰阶小字（黑底亮灰白 `#EEEEEE` / 中灰 `#969696`）
- CTA（预约观展/购票/入场）：强调色 + 右下角 64px 二维码，与左侧文字顶边/右缘对齐

## 次要文字降级（v4.31 铁律：降不透明度，不是变灰）

> 起因：潍坊风筝展英文名与主标题/非遗名视觉权重太近。第一步用 `mix(色, 灰128, 0.55)` 变灰，用户纠正「要降不透明度，不是变灰」——变灰会脏、发闷，且色相被污染。

- **弱化次要文字（英文名/副标签等）用 alpha 半透明，不用 mix 灰。**
- 实现：在独立 `RGBA` 透明层上用**原色相**绘制文字，再以降低的 alpha 贴回底图：
  ```python
  layer = Image.new("RGBA", img.size, (0,0,0,0))
  ld = ImageDraw.Draw(layer)
  ld.text(xy, text, font=font, fill=(255,255,255,120))  # 半透明白
  img.paste(layer, (0,0), layer)
  ```
- **alpha 参考**：深底次要英文名约 `120`（≈47%）；可 90–150 区间按「想多淡」调。保持色相为白/原色，只降不透明度，让底图透出。
- 验证：文字区像素 RGB 应仍是原色相（如白），只是明度被底图拉低；若明显偏灰则说明误用 mix 灰。
